# Benza — English local copy

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this directory and visit http://localhost:8000.

The main page is translated into English. The personal data policy link opens the original Russian page. Video reviews and external links require an internet connection; their content remains in the original language. The local copy has no form backend; contact Benza by phone or email.

Source: https://kazsbenza.ru/
